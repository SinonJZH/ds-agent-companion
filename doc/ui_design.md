# UI 设计规范

本文档只描述当前最新状态，修订记录见 [revisions.md](revisions.md)。

## 技术选型与架构形态

- 前端：单一 web 前端（Angular），桌面与移动同构，维护一套代码。
- 引擎：Python asyncio 单进程，内置 API 服务与前端静态资源托管，对外为本地 / 局域网 C/S 结构。
- 桌面：pywebview 壳窗口加载引擎服务的前端页面；桌面集成收窄为快捷键（页面层键盘事件）与系统通知（壳转发）；更深度集成（托盘等）初版不做。
- 移动端（后续）：浏览器 / PWA 访问同一服务。
- headless 部署：引擎进程可脱离任何前端常驻运行（NAS / 服务器，Docker），桌面壳与移动端都是它的客户端。
- 接口层：以 protobuf 为契约、ConnectRPC 承载——服务端 connect-python（ASGI），前端 connect-es 生成强类型 TypeScript 客户端；浏览器走
  Connect 协议（普通 HTTP POST + JSON，无需 gRPC-Web 代理，对反向代理与内网穿透透明）；对话流式输出走
  server-streaming；前端组件只依赖生成的客户端 service，接口调用即方法调用。
- 富文本：浏览器侧 markdown 渲染（markdown-it 或同类）+ 按消息条目分项更新节流；长会话采用虚拟滚动。

## 主题与颜色规范

- 深色主题，暗蓝背景。对比度按内容类型分级：
    - 阅读型正文（聊天消息、思考过程、记忆条目、提示词内容、日志）≥7:1（WCAG AAA；大号文字 ≥4.5:1）；
    - 界面短文本（时间戳、标签、按钮、导航、状态徽标、占位文字）≥4.5:1（WCAG AA；大号文字 ≥3:1）；
    - 禁用态控件文字与纯装饰性文字豁免。
- 颜色一律经 token 引用，禁止组件内写裸色值；token 按「前景色 × 适用底色」配对定义。
- 占位文字与主文字的区分采用「颜色 + 斜体」双手段（当前取值在 AAA 档）。
- 主按钮采用 `accent` 底 + `#0F172A` 深色文字；`border` 为非文字用途，对相邻底色保持 ≥3:1（非文字对比参考值）。
- 仓库内置对比度校验脚本，对全部 token 组合断言 ≥4.5:1，并断言正文用组合 ≥7:1，纳入测试；新增或调整 token 必须先过校验。

## 页面结构与导航

聊天窗口为主界面（启动即达），侧边栏导航切换二级页。页面集：

| 页面           | 定位                             |
|----------------|----------------------------------|
| 聊天窗口       | 主界面，全部会话交互             |
| 人设包管理     | 角色内容编辑（含人设层提示词）   |
| 提示词设置     | 全局层与场景默认层提示词         |
| 记忆管理       | 记忆浏览与修正                   |
| 调度与后台任务 | 调度项与后台任务运维、可观测入口 |
| 插件管理       | 插件启停与安全配置               |
| 系统设置       | 模型、时区、密钥等全局配置       |

## 各页面设计要点

### 聊天窗口（主界面）

- 顶部提供当前人设与场景切换。
- 场景形态区分：`private_chat` 为对话流视图；`sns_post` / `sns_reply` 为帖子 / 时间线视图，同窗口内按场景切换形态。
- 消息渲染：markdown 流式渲染；thinking 模式的 `reasoning_content` 以可折叠的思考过程区块展示。
- 主动会话：调度层触发的主动消息经系统通知提示；进入主界面后在对应时间线中穿插呈现，不打断用户当前输入。

### 人设包管理

- 编辑人设包全部内容：元信息、人设核心、世界观块、性格池（性格、权重、参考语料）、场景覆盖、记忆槽位。
- 人设包为数据目录下的目录包，本页编辑经引擎 API 写穿文件；支持 zip 导入导出。
- 人设层提示词块在本页编辑，与提示词设置页不重叠。

### 提示词设置

- 管辖范围：全局层块与场景默认层的槽位 / 变体；人设层归人设包管理。
- 所有层均可编辑；全局层（安全底线）编辑需显式确认，变更留版本历史、可回滚。
- 组装预览：任选场景调用 `build(scene, context)` 展示最终 messages（纯函数，无副作用）。

### 记忆管理

- 以浏览与修正为主，不做任意增删改（与 append-only 存储语义一致）。
- 浏览：四层笔记逐层下钻（`anchored_to` 锚点）、状态卡（心境 / 用户卡 / 关系状态）、向量条目；均支持按公开 / 隐私分区过滤与按日期检索。
- 修正类写操作：分区标签修正、状态卡修正、向量条目查重合并触发。

### 调度与后台任务

- 调度项列表：来源（用户 / LLM / 插件）、触发条件与频率、启停；展示数量与频率上限状态。
- 内置后台任务（蒸馏 / 晋升 / 压缩 / 心境抽取 / 记忆卫生）的运行状态与最近结果。
- 可观测入口：提示词组装日志、心境抽取与晋升决策日志的查看，支持排查「它为什么这么说」。

### 插件管理

- 插件清单（manifest 信息）与启停；危险操作白名单与确认门配置。
- 插件加载为启动扫描 + manifest 注册 + 重载，无运行时热替换；页面提供「重载插件」动作。

### 系统设置

- 场景级模型配置：场景 × 模型 × thinking 开关 × effort × 是否附带 tools；后台任务模型配置独立一组。
- IANA 时区配置（展示层渲染依据）。
- DeepSeek API key：经 .env 注入，设置页只做配置状态展示与编辑入口，密钥不进主库、不进仓库。

## 范围外（初版不做）

- 图片输入（`deepseek-flash` 已支持视觉，列为后续 TODO）。
- 系统托盘等更深度桌面集成（快捷键与系统通知之外的壳能力）。
- 移动端 PWA 封装与推送通知（浏览器直接访问已可用）。
